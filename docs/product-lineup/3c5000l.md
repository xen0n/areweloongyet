# 龙芯 3C5000L/3C5000L-LL

龙芯 3C5000L 和 3C5000L-LL 是龙芯公司于 2021 年推出的首款基于 LoongArch 架构的服务器处理器，标志着龙芯进军高性能服务器市场的重要一步。

## 基本规格

| 参数 | 3C5000L | 3C5000L-LL |
|------|---------|------------|
| 发布年份 | 2021 | 2021 |
| 指令集架构 | LoongArch | LoongArch |
| 微架构 | GS464V | GS464V |
| 核心数 | 16 | 16 |
| 频率 | 2.2 GHz | 2.0 GHz |
| 工艺 | 12/14 nm | 12/14 nm |
| L1 缓存（每核） | 64 KB 指令 + 64 KB 数据 | 64 KB 指令 + 64 KB 数据 |
| L2 缓存（每核） | 256 KB | 256 KB |
| L3 缓存（共享） | 16 MB × 4 | 16 MB × 4 |
| 功耗 | 150W @ 2.2 GHz | 125W @ 2.0 GHz |
| 浮点性能 | 560 GFLOPS | 512 GFLOPS |

## 架构特点

3C5000L 采用的是与 3A5000 相同的 GS464V 微架构，但核心数量大幅增加至 16 个，提供了更高的并行计算能力：

- 16 核心设计，每核支持四发射
- 四核心为一簇（cluster）的四簇设计
- 支持向量指令扩展（LSX、LASX）
- 具有 256 位向量处理能力
- 集成 8 通道 DDR4-3200 内存控制器
- 支持 PCIe 4.0 接口

## 产品差异

3C5000L 和 3C5000L-LL 的主要区别在于：

- **3C5000L-LL**：采用较低的工作频率以降低功耗，适用于对能效要求较高的场景
- **3C5000L**：采用标准频率，提供更高的单线程和多线程性能

## 市场定位

3C5000L 系列定位于：

- 企业级服务器
- 高性能计算（HPC）
- 云计算基础设施
- 数据中心应用

## 平台特性

3C5000L 服务器平台通常具备以下特点：

- 支持双路 CPU（总共 32 核心）
- 16 个内存插槽，最高支持 512GB 内存
- 丰富的 PCIe 扩展槽
- 支持多种高性能网络接口
- 支持龙芯 BIOS、龙芯固件和国产操作系统

## 历史意义

作为首款基于 LoongArch 架构的服务器处理器，3C5000L 系列对于龙芯生态系统的发展具有重要意义，它展示了龙芯在高性能计算领域的能力，为国产服务器市场提供了新的选择。
