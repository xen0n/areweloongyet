# 龙芯 3A5000/3B5000

龙芯 3A5000 和 3B5000 是龙芯公司于 2021 年推出的首款采用自主指令集架构（LoongArch）的处理器。这是龙芯从 MIPS 架构完全迁移到自主架构的里程碑产品。

## 基本规格

| 参数 | 规格 |
|------|------|
| 发布年份 | 2021 |
| 指令集架构 | LoongArch |
| 微架构 | GS464V |
| 核心数 | 4 |
| 频率 | 2.3-2.5 GHz |
| 工艺 | 12/14 nm |
| L1 缓存（每核） | 64 KB 指令 + 64 KB 数据 |
| L2 缓存（每核） | 256 KB |
| L3 缓存（共享） | 16 MB |
| 功耗 | 35W @ 2.5 GHz |
| 浮点性能 | 160 GFLOPS |

## 架构特点

3A5000/3B5000 采用的 GS464V 微架构是 LoongArch 的首个实现，具有以下特点：

- 四核设计，每核支持四发射
- 采用顺序执行的乱序完成模型
- 支持向量指令扩展（LSX、LASX）
- 具有 128 位向量处理能力
- 集成 DDR4-3200 内存控制器
- 支持 PCIe 3.0 接口

## 性能表现

在 SPEC CPU 基准测试中，3A5000 的成绩为：
- SPECint: 26.6（单线程），约 80（多线程）
- 相较上一代 3A4000，性能提升约 50%

## 市场定位

- **3A5000**：面向主流桌面电脑和工作站市场
- **3B5000**：与 3A5000 基本相同，但针对服务器优化

## 主板芯片组

3A5000/3B5000 处理器通常搭配龙芯自主研发的 7A1000 芯片组，提供：

- PCI Express 3.0 接口
- USB 3.0/2.0 接口
- SATA 3.0 接口
- 千兆以太网接口

## 历史意义

3A5000/3B5000 是龙芯公司实现自主指令集架构的重要里程碑，标志着中国处理器产业在核心技术上迈出了关键一步。作为首款 LoongArch 处理器，它为后续的产品线发展奠定了基础。
